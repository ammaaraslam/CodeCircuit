Hi👋 I'm **Ammaar Aslam**. I'm a 16 year-old self taught programmer/web developer from **Sri Lanka**.

I began my coding journey at the age of 12, and haven't stopped ever since. I am a daily learner with a great passion to solve problems through **Code** 💻 and to become a better **Software Engineer ✨**.

I work primarily with **Python** for building fun terminal based applications and **React** and **Gatsby** for building websites and web applications like Code Circuit. I'm currently learning flutter while writing on Code Circuit. 

I built Code Circuit as a side project, *(not only because it was fun building it*😉), but also to help other developers who to overcome the problems that come while coding, so they spend less time Googling or digging through issues on StackOverflow/Github and more time understanding and solving the problems at hand.
