Code Circuit is a blog about both front-end and back-end technologies, with a primary focus on **Python and Javascript**.<br />
Python is the first programming language that I learned when I was around 12 years old. Then I started to learn web development with simple HTML, CSS & JS, then moved deeper into front-end frameworks like React(*which is my favourite and the one that I use alot by the way* 😍). <br />
Nowadays, I use Python for automation, APIs and some occational projects and I use React & Gatsby for building websites.

## Aim 🎯
The main goal of Code Circuit is to share the knowledge that I gain in my *programming journey* and to help other developers like me to improve their programming skills.<br />
It is also a place of reference for myself *(I frequently go back to my old posts remind me how to something)*, so we are all in it together. I wouldn't write about something that I myself wouldn'd want to refer.😉


## Why Code *"Circuit"*?
There isn't a big story behind but if you really care about it, its because I like working *not only with software*, but also with **hardware**.<br />
That's it, but thanks for thinking about it😊.
