**Code Circuit** is a blog about both frontend and backend technologies built by [Ammaar Aslam](https://codecircuit.netlify.app/ammaar-aslam), with a primary focus on **Python (*& Sometimes NodeJS)* for backend, APIs, automation and React & Gatsby for frontend web development**. This is the place where I 'nerd' about programming and improve my current skills while helping others.

## Aim 
The main goal of Code Circuit is to share the knowledge that I gain in my *programming journey* and to help other developers like me to improve their programming skills.<br />
It is also a place of reference for myself *(I frequently go back to my old posts to remind me how to do something)*, so we are all in it together. I wouldn't write about something that I myself wouldn'd want to refer😉.

## Why Code *"Circuit"*
There isn't a big story behind but if you really care about it, its because I like working *not only with software*, but also with **hardware**.<br />
That's it, but thanks for thinking about it😊.

## Tools :toolbox:
This site is built with [Gatsby](https://codecircuit.netlify.app/topics/gatsby) *(a really cool and powerful static site genorator for **[React](https://codecircuit.netlify.app/topics/react)***), [Styled-Components](https://codecircuit.netlify.app/topics/styled-components) *(a CSS in Javascript tool for styling)* and [Netlify](https://codecircuit.netlify.app/topics/netlify) *(for hosting)*.
